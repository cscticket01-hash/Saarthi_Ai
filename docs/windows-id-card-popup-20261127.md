# Windows ID card popup — approved November 27

Native manifest card preview now opens a modal over the existing dashboard, with adaptive single/double portrait/landscape geometry, no front/back headings, close action, and horizontal Print/Download actions when space permits. Native preview never calls the PDF renderer. Green Blue Modern explicitly restores Print using the existing full-resolution print renderer. School branding uses only the current school's saved slot URL, file ID or inline image; a configured unavailable source fails closed. Added the missing Green Blue school address region and roll alias. Existing artwork, QR identities and sync/automatic PDF policy unchanged. Gallery and draft native routes use the same modal. Bulk branding inputs share the resolver. Legacy numeric teacher vector templates still use the existing PDF preview; they require separate native-equivalence migration before the all-template scope can be marked complete. Actual school data and visual/physical acceptance are unverified. No new workflow or production deployment. Tests added but not manually run.
